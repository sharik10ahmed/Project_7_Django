## ✨ Overview

**FutureStack** is an enterprise-grade, beautifully crafted E-Learning and Professional Development Web Application built on **Django 6**. Engineered with a clean modular architecture and powered by custom **Vanilla CSS glassmorphic aesthetics**, FutureStack delivers a friction-free learning environment for ambitious professionals.

> [!NOTE]
> FutureStack combines rigorous backend security (Email OTP 2-Factor Authentication, Session Management, and CSRF protection) with an immersive front-end featuring dynamic video hero headers, categorized mega-menus, and responsive course catalogs.

## 🏗️ System Architecture

FutureStack leverages Django's robust Model-View-Template (MVT) paradigm with an asynchronous email dispatch pipeline and decoupled session state management.

```mermaid
flowchart TD
    subgraph Client ["🖥️ Client / Browser"]
        A[User Browser] -->|HTTP GET/POST| B(Django URL Router)
    end

    subgraph Backend ["⚙️ Django 6.0 Core Engine"]
        B --> C{View Controller}
        C -->|Register & Validate| D[Session Staging Layer]
        D -->|Generate OTP| E[OTP Security Engine]
        E -->|HTML Email Template| F[SMTP Email Service (Gmail/TLS)]
        
        C -->|Verify OTP & Commit| G[(SQLite Database / ORM)]
        C -->|Query Catalog| G
        
        G -->|Model Dataset| H[Course & User Models]
        H -->|Context Data| I[Django Template Engine]
    end

    subgraph Frontend ["🎨 Responsive View Engine"]
        I --> J[HTML5 + CSS Tokens + ES6 JS]
        J -->|Render View| A
    end
```

### 🔐 Two-Factor OTP Registration Lifecycle

```
[ User Input ] ────────> [ Staged in Session ] ────────> [ 6-Digit OTP Generated ]
                                                                   │
[ Account Active ] <──── [ OTP Verification ] <── [ Delivered via SMTP Email ]
```

## ⚡ Quickstart & Installation

Follow these concise steps to set up FutureStack locally in under 2 minutes:

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/shariksosync/FutureStack.git
cd FutureStack/elearning
```

### 2️⃣ Initialize Virtual Environment

```bash
# On Windows (PowerShell / CMD)
python -m venv .venv
.venv\Scripts\activate

# On macOS / Linux
python3 -m venv .venv
source .venv/bin/activate
```

### 3️⃣ Configure Environment Variables

Duplicate the template and customize your credentials:

```bash
# On Windows
copy .env.example .env

# On Linux / macOS
cp .env.example .env
```

### 4️⃣ Apply Database Migrations

```bash
python manage.py makemigrations
python manage.py migrate
```

### 5️⃣ Create Superuser (Admin Access)

```bash
python manage.py createsuperuser
```

### 6️⃣ Launch the Development Server

```bash
python manage.py runserver
```

Navigate to **[`http://127.0.0.1:8000/`](http://127.0.0.1:8000/)** in your browser to experience FutureStack!

## 📧 Email & OTP Configuration

FutureStack features built-in SMTP delivery with rich branded HTML templates for OTP verification and registration confirmations.

### Configuration Guide (`.env`):

```ini
EMAIL_BACKEND=django.core.mail.backends.smtp.EmailBackend
EMAIL_HOST=smtp.gmail.com
EMAIL_PORT=587
EMAIL_USE_TLS=True
EMAIL_HOST_USER=your_email@gmail.com
EMAIL_HOST_PASSWORD=your_16_digit_google_app_password
DEFAULT_FROM_EMAIL=your_email@gmail.com
```

> [!TIP]
> **Using Gmail?** Generate an **App Password** by visiting [Google Account Security](https://myaccount.google.com/security) → **2-Step Verification** → **App passwords**.

## 📊 Database Models

<details>
<summary><strong>🔍 Click to expand the <code>Course</code> Data Schema</strong></summary>

```python
class Course(models.Model):
    title = models.CharField(max_length=200)
    description = models.TextField()
    banner_image = models.ImageField(upload_to='courses/', blank=True, null=True)
    banner_image_url = models.URLField(blank=True, null=True)
    original_price = models.DecimalField(max_digits=10, decimal_places=2)
    payable_amount = models.DecimalField(max_digits=10, decimal_places=2)
    instructor_name = models.CharField(max_length=150)
    duration = models.CharField(max_length=100)
    course_overview = models.TextField(blank=True)
    last_remarks = models.TextField(blank=True)
    
    # UI Metadata
    category = models.CharField(max_length=150, default='LEADERSHIP AND PERSONAL DEVELOPMENT')
    level = models.CharField(max_length=100, default='Advanced')
    modules_count = models.IntegerField(default=6)
    students_count = models.IntegerField(default=5)

    @property
    def discount_percentage(self):
        """Calculates dynamic savings % on the fly."""
        if self.original_price > 0:
            return int(round(((self.original_price - self.payable_amount) / self.original_price) * 100))
        return 0
```
